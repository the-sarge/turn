# AGENTS.md

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `the-sarge/turn` via the `gh` CLI; external PRs are **not** a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage labels use their default names (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`); `ready-for-agent` is shared with `architecture-handoff`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` at the repo root (created lazily by `/domain-modeling`) and ADRs in `docs/adr/`. See `docs/agents/domain.md`.
